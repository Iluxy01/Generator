# Холст

Экран блокировки как общий лист с другом. Рисуешь пальцем прямо на обоях, и рисунок сразу появляется на его экране блокировки. А его рисунки — на твоём.

**Скачать:** [Holst.apk](https://github.com/Iluxy01/Generator/releases/latest/download/Holst.apk)

## Как начать

1. Поставь APK и открой приложение.
2. Выбери картинку для обоев или чистый лист. С этого момента экран блокировки стал холстом.
3. Отправь другу код: он ставит то же приложение и вводит его.
4. Разреши показ на экране блокировки: без этого Android не даст холсту открываться.
5. Заблокируй телефон, включи экран и рисуй. Чтобы разблокировать, потяни полоску внизу вверх.

## Как это устроено

- **Слой на экране блокировки.** Android не передаёт настоящим обоям касания, когда телефон заблокирован. Поэтому поверх экрана блокировки лежит окно с той же самой картинкой (`LockActivity`). Выглядит и работает как обои.
- **Настоящие обои.** После каждого изменения картинка с рисунками записывается в обои экрана блокировки. Обои рабочего стола не меняются.
- **Связь без своего сервера.** Штрихи идут через бесплатные публичные ретрансляторы Nostr. Они шифруются (AES-256-GCM) ключом из 12-значного кода, сам код в сеть не уходит.
- **Без сети ничего не теряется.** Штрихи лежат на телефоне и уходят при появлении связи, пропущенное догоняется автоматически.

## Сборка

Каждый пуш в `main` собирает APK в GitHub Actions, обновляет релиз и прогоняет `ci/e2e.py` на Android-эмуляторе. Там второго телефона изображает скрипт со своей реализацией протокола.

Локально: `./gradlew assembleRelease` (нужны JDK 17 и Android SDK).

Ключ подписи `keystore/holst.jks` лежит в репозитории, чтобы обновления ставились поверх старой версии. Для публичного распространения его нужно заменить и хранить в секретах.
